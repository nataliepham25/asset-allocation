A small single-page app for calculating asset allocation, built with Vue 3, TypeScript, and Vite. Run `npm install` to set up dependencies, `npm run dev` to start the local dev server, `npm run build` to produce a production build, `npm run test` to run the unit test suite, and `npm run lint` / `npm run format` to check and fix code style.
